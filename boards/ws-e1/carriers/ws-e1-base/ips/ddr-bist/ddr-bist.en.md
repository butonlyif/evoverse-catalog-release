# DDR BIST (Memory Built-In Self Test)

## Source Demos
- `demos/ddr-memtest/` (formerly DDR_TEST, standalone BIST test project)
- `demos/si5338-clock-config/` (formerly SI5338, SoC-integrated APB-controllable version)

## Hard IP Configuration
- **DDR controller**: TJ180A484 LPDDR4 2133MHz (board-level hard IP, configured via peri.xml)
  - Configuration parameters: see constraints/mem_test.peri.xml

> Note: this IP is a pure RTL logic-layer BIST and does not include the DDR controller hard IP itself. The DDR controller is configured and generated by the Interface Designer (peri.xml).

## RTL Files

|------|------|

## Interfaces
- **AXI4 port 0** (axi0_*): 512-bit data width, used for BIST write testing
- **AXI4 port 1** (axi1_*): 512-bit data width, used for BIST read verification
- **Clocks**: i_sys_clk (system clock), axi0_ACLK, axi1_ACLK (DDR memory clocks)
- **LEDs/switches**: o_led[5:0] (test status indication), i_sw[1:0] (test mode selection)
- **APB3** (design_modules.v): PSEL, PENABLE, PWRITE, PADDR, PWDATA, PRDATA (BIST register control)

## Use Cases
LPDDR4 memory testing and verification on the ws-e1-base carrier board. Provides two usage modes:
1. **Standalone mode** (ddr-memtest, formerly DDR_TEST): runs the BIST automatically after power-up and reports pass/fail via LEDs; suitable for production-line testing.
2. **SoC-integrated mode** (si5338-clock-config, formerly SI5338): the RISC-V SoC controls BIST start/stop and result readout through APB3 registers; suitable for run-time memory diagnostics.
