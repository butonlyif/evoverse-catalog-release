# Stage-0 — ws-e3 Skeleton Project

`stage0` is the minimal runnable project that the EvoVerse SDK (`evoverse new-project`) generates for the [ws-e3](../../ws-e3.md) standalone board: an LED blink design that occupies only the three skeleton signal classes — clock, reset and LED — to exercise the full "project generation → synthesis → place-and-route → programming → on-board observation" chain.

## Hardware Resource Usage

| Signal | Direction | Pin | Level | On-board resource |
|---|---|---|---|---|
| `clk_50m` | in | R3 | 1.8 V LVCMOS | on-board system clock |
| `arst_n` | in | A3 | — (bank default) | active-low reset button |
| `led_user` | out | C1 | — (bank default) | user LED |

The signals follow the SDK's `clk_50m` naming convention; the actual main frequency is determined by the board crystal, and the SDC constrains it at 100 MHz (10 ns period). Pins come from automatic parsing of the [ws-e3.md](../../ws-e3.md) board pin map. For levels, the clock is constrained with the explicit IO_STANDARD `1.8 V LVCMOS`; `arst_n` and `led_user` are not explicitly specified and inherit the defaults of their banks.

## Design Notes

`rtl/top.v` (top module `ws_e3_stage0`) is purely synchronous single-domain logic:

- A 24-bit counter increments on the rising clock edge and is asynchronously cleared by `arst_n`;
- The counter MSB `cnt[23]` directly drives `led_user`, giving a blink period of about 0.34 s at 50 MHz; at the actual 100 MHz main frequency the blink rate doubles accordingly.

No PLL and no other IP dependencies — the minimal workload for verifying the health of the ws-e3 board.

## File List and Generation

```text
stage0/
├── rtl/top.v                       # skeleton RTL (auto-generated)
├── constraints/
│   ├── ws_e3_stage0.pins.isf       # pins and bank voltages (auto-generated)
│   └── ws_e3_stage0.sdc            # main clock constraint (auto-generated)
├── ws-e3-stage0.xml                # Efinity 2026.1 project (auto-generated)
└── ws-e3-stage0.peri.xml           # Interface Designer database (generated artifact)
```

All files are generated by the SDK from the board pin map; **do not edit them by hand**. The timing constraint declares only the main clock: `create_clock -name clk_50m -period 10.000 [get_ports clk_50m]`.

To change pins, modify the board pin map and regenerate; to carry real functionality, create a new jacket instead of modifying stage0.

## Build and Programming

1. Open `ws-e3-stage0.xml` with Efinity 2026.1 (device TJ375N484X).
2. Run Synthesis → Place & Route → Generate Bitstream in order.
3. After programming and power-on, observing the user LED blinking periodically means success; if the LED stays dark, first check the 1.8 V bank voltage setting and the reset polarity.
